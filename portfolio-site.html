Why rebuild it

The first version of this site, from April 2026, was a dark template with a lime accent and three projects. By September the work had changed: most of my time was going into Cairn and Plenum, and those apps had grown a real design system with their own palette, type and component rules. Keeping the portfolio in a different visual language than the product I was showing off made no sense, so the site now runs on the same tokens.

What changed

  • Palette and type. Light mode is the default, on paper rather than black. Every colour has a dark twin in the same warm family, and the System / Light / Dark control in the navigation is the same segmented control both apps use.
  • Page transitions. Navigation between pages uses cross-document view transitions where the browser supports them, with a small JavaScript fade as a fallback. The navigation bar is pinned so only the content moves.
  • Real imagery. The gradient placeholders are gone. The Cairn & Plenum cover is a drag-to-compare wipe between the fused LiDAR geometry and the photo-textured splat of the same hallway.
  • Projects page. Two new case studies, filter chips, and a card per project coloured by its discipline hue.
  • Motion with limits. Reveals, counters and the compare wipe all stop when the visitor has asked for reduced motion.

How it was built

I iterate on the site with Claude Code, the same way I work on the apps: describe the change, review the diff, load the page, look at it. Git tracks every revision and GitHub Pages publishes straight from the main branch, so a change is a commit and a push.
