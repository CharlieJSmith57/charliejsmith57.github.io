How I work

Decisions I make on purpose.

The same rules I hold the software to, applied to everything else I build.

Field-first

A capture app has to work with no Wi-Fi, gloves on, in a bright doorway. If it only works at the desk, it doesn’t ship.

Build the whole chain

Capture, pipeline, and viewer are one system. Owning every link is how a bug in registration gets fixed in the pipeline, not patched in the UI.

Look before claiming

A passing test count isn’t a result. I render it, measure it, and check the negative control before I call something fixed.
